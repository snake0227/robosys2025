# stdin_kadaiコマンド
![test](https://github.com/snake0227/robosys2025/blob/main/.github/workflows/test.yml/badge.svg)

  自動車の最高速を計算するコマンド

# 使い方
  馬力、エンジン回転数、車重、最終減速比、最高速ギア比、横幅、全高、最低地上高の順で入力してください。
  このとき、数値一つごとに改行してください。

# 実行環境
  Ubuntu 22.04
  Python3.7~3.10
